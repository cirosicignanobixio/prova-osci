# Oscilloscopio didattico — Laboratorio autonomo

Versione autonoma dell’oscilloscopio virtuale, priva di verifiche, voti, registrazioni e servizi aggiuntivi. Aprire `index.html` in un browser.

Ogni utente gestisce localmente i quattro generatori e lo strumento. Le impostazioni sono salvate solo nel browser utilizzato. Pulsante “Ripristina” per ricominciare.

Questa versione non modifica il repository `osci` e non richiede hosting per provarla offline.
